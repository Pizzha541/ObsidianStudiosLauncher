<h1 align="center">Obsidian Studios Launcher</h1>

<p align="center">
  Launcher personalizado de Obsidian Studios para gestionar y actualizar modpacks de Minecraft de forma sencilla.
</p>

---

## ✨ Características

- Actualización remota de modpacks mediante distribución JSON.
- Perfiles personalizados para diferentes proyectos de Obsidian Studios.
- Descarga automática de librerías, mods y versiones de Minecraft.
- Integración con Discord para soporte y anuncios.
- Interfaz limpia y enfocada al usuario.

---

## 🚀 Requisitos

- Node.js 20.x
- Git
- Java 17+ (para ejecutar y probar los modpacks)

---

## 🛠️ Desarrollo

```bash
# Clonar el repositorio
git clone https://github.com/Pizzha541/ObsidianStudiosLauncher.git
cd ObsidianStudiosLauncher

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm start
