🌌 ¿Qué es Obsidian Studios Launcher?

Obsidian Studios Launcher es una plataforma moderna basada en Electron que permite:

• Ejecutar modpacks avanzados sin configuraciones manuales.
• Descargar automáticamente mods, librerías, configuraciones y assets.
• Mantener el cliente siempre sincronizado con el servidor.
• Ofrecer una experiencia 100% personalizada al estilo Obsidian Studios.
• Usar distribuciones remotas mediante archivos distribution.json.

Es el launcher oficial utilizado para series, eventos, proyectos y mundos de Minecraft creados por Obsidian Studios.

✨ Características principales
---
• Actualización automática del launcher mediante GitHub Releases.
• Descarga inteligente de modpacks usando distribución remota.
• Personalización completa del branding de Obsidian Studios.
• Integración directa con Discord para soporte y anuncios.
• Compatibilidad multi-plataforma dependiendo de los builds.

📦 Instalación
---
Abre la sección Releases del repositorio:
https://github.com/Pizzha541/ObsidianStudiosLauncher/releases

Descarga la última versión del instalador con nombre similar a:
ObsidianStudiosLauncher-Setup-x.y.z.exe

Instálalo y ejecútalo normalmente.

Después de la primera instalación, el launcher se actualizará automáticamente cuando detecte nuevas versiones.

🛠️ Compilar desde el código fuente
---
1. Clonar el repositorio

git clone https://github.com/Pizzha541/ObsidianStudiosLauncher.git

cd ObsidianStudiosLauncher

2. Instalar dependencias

npm install

3. Ejecutar en modo desarrollo

npm start
Esto abre el launcher en modo desarrollador, con recarga automática al modificar archivos.

🔨 Crear instaladores (Build / Dist)
---
Para generar el instalador del launcher, usar el comando siguiente:
npm run dist

Al finalizar, en la carpeta dist aparecerán archivos como:

• ObsidianStudiosLauncher-Setup-x.y.z.exe
• latest.yml
• ObsidianStudiosLauncher-Setup-x.y.z.exe.blockmap (si existe)

Estos archivos deben subirse a GitHub Releases para que el sistema de actualizaciones automáticas funcione correctamente.
